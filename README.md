# Trading Journal Platform

A professional full-stack trading journal platform designed for:
- trade tracking
- emotional discipline analysis
- risk management
- trading analytics

Built using:
- Angular
- Spring Boot
- PostgreSQL
- Docker
- Jenkins
- Kubernetes
- AWS

## Planned Features
- Trade management
- Emotional tracking
- Risk analytics
- Prop trading rule engine
- Performance dashboards
- Event-driven architecture

## Architecture
Frontend: Angular
Backend: Spring Boot
Database: PostgreSQL
DevOps: Docker, Jenkins, Kubernetes
Cloud: AWS

## Status
Phase 1 MVP in progress.
